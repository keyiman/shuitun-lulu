# 水豚噜噜

这是一个为 Codex pets 打磨出来的透明背景动画宠物。

## 内容

- `pet.json`：宠物定义
- `spritesheet.webp`：最终动画图集
- `spritesheet.png`：无损备份图集
- `preview/`：若干预览动图

## 特点

- 透明背景
- 圆润橙黄色水豚本体
- 河豚造型斜挎包
- 白色眼球、黑色瞳孔居中
- 本体带手指

## 使用

把 `pet.json` 和 `spritesheet.webp` 放到支持 Codex pet 的位置即可。

## 说明

本仓库公开的是最终可用成品和必要说明，不包含完整的生成过程。
